Accessibility

A bedtime reminder should meet you where you are.

Beddy Butler combines native macOS controls with sound, persistent visual state, and silent notification choices.

Ways to receive a nudge

  • Sound: hear an original voiced reminder with independent volume control.
  • Visual: keep a persistent menu bar badge until it is acknowledged.
  • Both: combine the voice and badge without duplicating the scheduled nudge.
  • Notification Centre: optionally add a silent local alert with Acknowledge, Snooze, and Pause actions.

macOS accessibility support

  • Native control names, values, hints, and keyboard shortcuts support VoiceOver and Full Keyboard Access.
  • Important state uses text and symbols as well as colour.
  • Reduced Motion keeps a stable character pose.
  • Reduced Transparency keeps content readable with an opaque material fallback.
  • Resizable and scrollable preferences preserve access to controls at the supported minimum window size.

What the voices are like

The visible description beside each preview communicates the character of the sound without requiring it to be heard.

  • Shy: a quiet, discreet, and polite reminder.
  • Insistent: a firmer, more direct prompt.
  • Zombie: a theatrical, exaggerated, intentionally startling last resort.

A reviewed, line-by-line transcript catalogue is planned. The app's visual badge and Tonight state already provide the full scheduling action without depending on spoken content.

How accessibility is verified

Automated tests cover accessible control identifiers, scheduling behaviour, persistent visual state, motion fallback, and the critical macOS accessibility hierarchy. Every release candidate also retains person led VoiceOver, keyboard, contrast, transparency, display, sleep, wake, and audio route checks. Automated evidence never replaces those checks.

Report an accessibility problem

Use the dedicated accessibility report form. Include the Beddy Butler version, macOS version, the assistive technology or display setting in use, and the smallest safe description of what happened. Omit private bedtime details.

Current boundary: support is described for the current release candidate. Person led acceptance is recorded again for every exact version, build, and source candidate before public distribution.
